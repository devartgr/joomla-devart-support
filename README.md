# DevArt Support for Joomla

Ticket desk for Joomla 6 with a registered-user site portal and an administrator staff desk. Built for large sites, high traffic, and simple day-to-day support work.

## Current Status

Current package version `1.0.0`. Stay on `1.0.0` until the first public release is declared. See `docs/operations.md` for Cloudflare and update notes.

- Package `pkg_devartsupport`
- Component `com_devartsupport`
- Privacy plugin `plg_privacy_devartsupport`
- Action Log plugin `plg_actionlog_devartsupport`
- Task plugin `plg_task_devartsupport`
- Site portal for registered users (own tickets: list, create, view, reply, priority, close/reopen)
- Portal and administrator private attachments (configurable types; portal enable switch)
- Statuses `open` and `closed` only
- Categories and priorities `low`, `normal`, `high`, `urgent`
- Tools submenu with Email Settings and Options hubs
- Staff email notifications for new tickets, replies and status changes
- GitHub update server via root `update.xml`
- No guest tickets, assignment, modules or live chat in this product line yet

## Requirements

- Joomla 6+
- PHP 8.3+
- Modern MariaDB/MySQL

No Joomla 3/4/5 compatibility. No PHP 7.x or PHP 8.0–8.2 compatibility.

## Package Inventory

- `com_devartsupport` — administrator staff desk and site portal
- `plg_privacy_devartsupport` — Joomla Privacy export/remove
- `plg_actionlog_devartsupport` — Joomla Action Log for ticket mutations
- `plg_task_devartsupport` — scheduled purge of expired private attachments

## Languages

Administrator, site and package language packs:

- English (`en-GB`) — source of truth
- Greek (`el-GR`) — curated
- French, German, Spanish, Italian, Brazilian Portuguese
- Czech, Dutch, Polish, Russian, Ukrainian, Japanese, Turkish, Chinese Simplified

Language keys and format specifiers are never translated.

## Repository Layout

- `source/` — the only development source
- `builds/` — unverified packages generated by the build script
- `releases/` — official packages moved manually by the user
- `scripts/` — validation and packaging
- `docs/` — architecture and current state
- `qa/` — Joomla installation and functional QA

## Validate and Build

```shell
php scripts/validate.php
php scripts/build.php
```

Install the generated ZIP with Joomla CLI on both local smoke (`demo3`) and harness (`joomla6_tests`) sites before claiming QA PASS.
