# DevArt Repository Template

Version: 1.1.0
Status: Generic reusable template
Updated: 2026-08-04

## About

This repository is the generic DevArt Joomla repository template. The template
version tracks improvements to repository infrastructure, scripts, and
documentation — it is **not** the version of any bootstrapped product.

## Template Baseline

- Generic `AGENTS.md` with bootstrap placeholder for project-specific rules
- Generic `PROJECT_STATUS.md`, `README.md`, and `CHANGELOG.md` placeholders
- Generic `scripts/validate.php` and `scripts/build.php`
- Generic documentation under `docs/` and `qa/`
- New product bootstrap checklist
- Four reusable development prompts

## Bootstrap

Copy this template, follow `docs/new-product-checklist.md`, add product sources
under `source/`, then validate, build, and complete Joomla QA.
